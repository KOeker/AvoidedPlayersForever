# Changelog

## 0.2.2

- Add players by first and last name from the social tab.
- Hide matching players and group leaders in the Forever Group Finder, or outline their rows in red and show the saved reason on hover.
- Refresh open Group Finder views when players are added or removed and when the filter is toggled.
- Decline incoming group invitations from confirmed avoided characters when the client allows it.
- Use one player icon for all avoid list entries.
- Limit native Ignore requests to prevent repeated system messages.

## 0.2.1

- Added account-wide avoid notes, supported player context menus, and integration with WoW's native Ignore list.
- Added a searchable social tab with class icons, reasons, and a remove button on each row.
- Added applicant filtering for Blizzard's Group Finder. Matching applications are hidden by default. Turning off hiding highlights matches in red and shows the reason on hover.
- Moved settings above the search box and refresh the applicant display when combat ends.
- Added original artwork for the project and WoW's addon list.
- Simplified the project layout and updated the English documentation.
